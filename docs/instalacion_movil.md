# Guía de Instalación y Configuración - CatálogoPro

## 1. Requisitos del Dispositivo / Entorno
- **Plataforma:** React Native / Expo Go / Android 8.0+ o iOS 12.0+.
- **Entorno de Desarrollo:** Node.js (v16 o superior), gestor de paquetes `npm` o `yarn`.
- **Almacenamiento Libre:** Mínimo 100 MB.

## 2. Procedimiento de Ejecución
1. Clonar el repositorio localmente o abrir en un entorno React Native.
2. Ejecutar el comando de instalación de dependencias:
   ```bash
   npm install

npx react-native start
# o si utilizas Expo:
npx expo start
